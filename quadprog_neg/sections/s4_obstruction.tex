\section{Where the guarantee comes from, and where it goes}
\label{sec:obstruction}

\subsection{Bound constraints: the guess cannot be bad}

Consider first $\min_{x \ge 0} \tfrac12 x\T G x - a\T x$, so that $C = I$ and
$m = n$. The system~\eqref{eq:pdassolve} on a candidate set $\Active$ is then
\begin{equation}
  \bigl(I_{\cdot\Active}\T G^{-1} I_{\cdot\Active}\bigr)\lambda_\Active
  = \bigl(G^{-1}\bigr)_{\Active\Active}\lambda_\Active
  = b_\Active - x_{u,\Active},
  \label{eq:principal}
\end{equation}
whose coefficient matrix is a \emph{principal submatrix} of $G^{-1}$. Since
$G^{-1} \succ 0$, every principal submatrix of it is positive definite, so
$G^{-1}$ is a $P$-matrix and every principal pivot is well defined, whatever the
guess. That is the hypothesis under which block principal pivoting with a
least-index guard terminates finitely at the unique
solution~\cite{judice1994,murty1988,cottle1992}, and the guarantee survives inexact
inner solves once their residual is small against the problem's decision
margin~\cite{schmelzer2026nncg}. The guess is safe because no guess can be bad:
the set of admissible candidate sets is all $2^n$ of them.

\subsection{General constraints: the guess carries a rank condition}

None of that is available for general $C$. The statement is elementary and we give
it in full, because the point is exactly which quantifier moves.

\begin{proposition}[The dual Hessian of a guess]\label{prop:guessrank}
Let $\Active$ have size $k$ and $A = C_\Active$. Then $A\T G^{-1} A \succ 0$ if
and only if $\rank A = k$, and $A\T G^{-1}A$ is singular otherwise.
\end{proposition}

\begin{proof}
Write $G^{-1} = L L\T$ with $L$ nonsingular. For $v \in \R^k$,
$v\T A\T G^{-1} A v = \norm{L\T A v}^2$, which vanishes if and only if $Av = 0$
since $L\T$ is nonsingular. So $A\T G^{-1}A \succeq 0$ always, with null space
exactly $\ker A$, which is trivial precisely when $\rank A = k$.
\end{proof}

In the bound case $A$ is a set of distinct columns of the identity and
$\rank A = k$ holds for every $\Active$, which is~\eqref{eq:principal} again. For
general $C$ it holds for some $\Active$ and fails for others: a guess may name
$k > n$ constraints, or $k \le n$ linearly dependent ones, and then the pivot
of~\eqref{eq:pdassolve} is undefined. Rank of a submatrix of $C$ is a property of
the guess, not of the data. There is no $P$-matrix to appeal to, and
correspondingly no theorem to inherit.

This is the same rank condition that Proposition~\ref{prop:sub} already carries.
What changes between the walk and the guess is not the condition but who
discharges it. In the walk it is discharged by the step rules and never tested
(Remark~\ref{rem:walk}); in the guess it is discharged by nothing and must be
tested.

\subsection{The bad guess is reached by the method's own rule}

One might hope the failure needs an adversary. It does not: the starting
guess~\eqref{eq:start} produces it on constraint sets a modelling language
produces by accident.

\begin{proposition}[A singular guess before the first repair]\label{prop:reachable}
Let $p \neq q$ be inequality indices with $c_p = c_q$ and $b_p \le b_q$. If
$c_p\T x_u < b_p$, then $\{p,q\} \subseteq \Active_0$ and $C_{\Active_0}$ is rank
deficient, so~\eqref{eq:pdassolve} has no solution on $\Active_0$.
\end{proposition}

\begin{proof}
The membership test in~\eqref{eq:start} puts $p$ into $\Active_0$ by hypothesis,
and then $c_q\T x_u = c_p\T x_u < b_p \le b_q$ puts $q$ there too.
Then $C_{\Active_0}$ has two identical columns, so its rank is below its column
count, and $C_{\Active_0}\T G^{-1} C_{\Active_0}$ is singular by
Proposition~\ref{prop:guessrank}.
\end{proof}

Duplication is the most elementary instance and not the only one: what the
argument needs is a linear dependence among constraints that the unconstrained
minimiser violates simultaneously, so any nontrivial dependence among the normals
will do provided $x_u$ violates all of them at once; for normals summing to zero
that requires $\sum_i b_i > 0$. Duplicated constraints are not exotic. They arise whenever a model is
assembled programmatically from overlapping rules, which is how portfolio and
control models are usually built.

Note where the failure sits. It is not that the method converges to the wrong
point, or cycles between two sets. The very first subproblem is undefined, before
any repair has been performed and therefore before any rule governing repairs has
had an opportunity to act.

\subsection{Why the obstruction is structural}
\label{ssec:structural}

Block exchange can also cycle, and for cycling the standard remedy is a least-index
rule that flips only the lowest-indexed offending constraint, after Bland's rule
for the simplex method and Murty's least-index rule for linear complementarity
problems~\cite{murty1988}. In the bound-constrained case that remedy comes with a
theorem. The theorem does not survive the generalisation, and the reason is not
that the right rule has yet to be found.

A rule of that kind is a map from the history of the iteration to the next
candidate set. It can address cycling, which is a property of the sequence of
sets. It cannot address singularity, which is a property of a single set:
Proposition~\ref{prop:reachable} exhibits a failure at the first set the method
names, where there is no sequence yet. A rule could in principle avoid singular
sets, but only by testing them, which is the factorisation the exchange was meant
to make cheap, and only by departing from the set the signs of~\eqref{eq:repair}
point at, which is the whole content of the method. Either way what results is no
longer the block exchange.

That reading is consistent with the repair the literature offers, and this is the
strongest evidence for it we can give. Curtis, Han and
Robinson~\cite{curtis2015pdas} recover global convergence by carrying an index set
auxiliary to the active-set estimate, which holds the indices that would otherwise
cycle. That changes what the method carries, not the order in which it exchanges.
Our claim is that it had to: no reordering recovers the bound-constrained theorem
when the subproblem on the chosen set may be singular. We state this as a
diagnosis rather than an impossibility theorem, because it quantifies over rules
rather than over instances, and a rule that carries extra state is outside its
scope by construction.
